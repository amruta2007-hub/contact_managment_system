# Contact Management System

## Project Title

Contact Management System using Python

## Overview

The Contact Management System is a command-line Python application that helps users store and manage contact information efficiently.
It allows users to add, view, search, update, and delete contacts while storing the data in a JSON file. The system also supports importing and exporting contacts using CSV format.

## Objectives

• To develop a simple command-line application for managing contacts.
• To practice file handling using JSON and CSV in Python.
• To implement CRUD operations (Create, Read, Update, Delete) for contact management.

## Features

• Feature 1: Add Contact – Users can add new contacts with details like name, phone number, email, and category.
• Feature 2: Search and View Contacts – Users can search contacts by name and view all stored contacts.
• Feature 3: Update and Delete Contacts – Existing contacts can be modified or removed from the system.
• Feature 4: Import/Export – Contacts can be exported to CSV or imported from CSV files.

## Technologies Used

• Python 3.8+
• JSON (for data storage)
• CSV (for import/export functionality)
• Command Line Interface (CLI)

## Installation

1. Clone or download the project

2. Navigate to the project folder

3. Install dependencies (if any):

```
pip install -r requirements.txt
```

## How to Run

1. Open terminal / command prompt

2. Navigate to the project folder

3. Run the main script:

```
python main.py
```

4. Follow the on-screen menu options to manage contacts.

## Expected Output

The program will display a menu in the terminal allowing users to manage contacts. Users can add, view, search, update, or delete contacts, and the data will be saved automatically in the contacts.json file.
