# Contact Management System Tutorial

## Getting Started
1. Run `python main.py` to start the CLI.
2. Follow the menu to add, view, search, update, or delete contacts.
3. Use import/export options for JSON/CSV files.

## Example Commands
- Add a new contact: Enter all required fields.
- Search: Enter name, phone, or category.
- Export: Choose JSON or CSV format.
- Import: Provide path to JSON/CSV file.

## Data Structure
Each contact includes:
- name
- phone
- email
- address
- category
- date_added

## Notes
- Data is saved in `data/contacts.json`.
- Exports are saved in `exports/`.
- See README.md for more info.
